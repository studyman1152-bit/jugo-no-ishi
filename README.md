# 十五の石

龍安寺の石庭と方丈の模型。ブラウザで開くと、方丈の畳の間から縁側へ歩いて出て、座って石を数える。
座る位置を変えると、見えている石の数が変わる。

https://studyman1152-bit.github.io/jugo-no-ishi/

- 龍安寺とは関係のない、個人が作った模型です。
- 石の位置は、鈴木広隆・藤本佳則・辻剛史「龍安寺石庭配石パターンの図形科学的分析」（図学研究）の配置図から読み取りました。
  石の形と高さ、縁側の幅、軒の出は写真からの見当で、実物とは違います。襖絵は実物ではなく、描いた墨の山水です。
- 光と影は Blender（Cycles）で画像と頂点の色に焼き、three.js で表示しています。1枚の HTML で完結し、外部のファイルは読みません。
